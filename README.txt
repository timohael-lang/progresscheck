DEVTEAM — сайт для набора разработчиков

ФУНКЦИИ:
- Главная страница
- Всплывающая анкета
- Telegram-уведомления
- Админ-панель /admin
- PostgreSQL база данных
- Статусы кандидатов
- Поиск заявок
- Удаление заявок

ДЕПЛОЙ:

1. Создай PostgreSQL базу в Supabase.
2. Получи строку подключения DATABASE_URL.
3. Создай хеш пароля командой:
   python generate_password.py

4. Загрузи проект на GitHub.
5. Создай Web Service на Render.
6. Добавь переменные окружения:
   DATABASE_URL
   BOT_TOKEN
   ADMIN_ID
   ADMIN_USERNAME
   ADMIN_PASSWORD_HASH
   SECRET_KEY

7. Запусти сайт.

Админ-панель:
https://АДРЕС-САЙТА/admin

ВАЖНО:
- Токен Telegram должен оставаться секретным.
- Не загружай .env на GitHub.
- Не используй старые опубликованные токены.
- Для публичного сайта рекомендуется добавить
  Cloudflare Turnstile и политику конфиденциальности.
- Уведомления кандидатам автоматически не отправляются:
  администратор связывается с ними по оставленным контактам.
- В админ-панели отображаются 200 последних заявок.
